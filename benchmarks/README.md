# Benchmarks 性能测试套件

本目录包含 YTsaurus 系统的性能测试和基准测试工具。

## 目录结构

- **run/** - 测试运行器
  - `common.py` - 通用测试工具函数库
  - `qt_run.py` - 查询性能测试运行器
  - `upload_metrics.py` - 测试指标上传工具
  - `queries/` - 查询测试用例
  - `public_pragmas/` - 公共编译指令
  - `__main__.py` - Python 模块入口点

- **ya.make** - 构建配置文件
  - 定义了基准测试组件的构建规则

## 功能特性

### 查询性能测试
- 支持 YQL 查询语言性能测试
- 提供多种查询场景的测试用例
- 自动收集和分析查询执行指标

### 测试工具集
- 通用的测试框架和工具函数
- 指标收集和上传机制
- 测试结果的可视化支持

## 使用方法

### 运行基准测试
```bash
# 使用 Python 模块方式运行
python -m benchmarks.run

# 或直接运行测试脚本
python benchmarks/run/qt_run.py --config config.yaml
```

### 自定义测试用例
1. 在 `queries/` 目录下添加新的查询文件
2. 配置测试参数
3. 运行测试套件

### 收集测试指标
```bash
python benchmarks/run/upload_metrics.py --test-results results.json
```

## 测试类型

### 查询性能测试
- 单表查询性能
- 多表 JOIN 查询性能
- 聚合查询性能
- 复杂分析查询性能

### 负载测试
- 并发查询压力测试
- 大数据量处理性能测试
- 系统资源利用率测试

## 依赖项

- Python 3.8+
- YTsaurus Python 客户端库
- YTsaurus 查询引擎
- 测试数据集

## 实现原理

本基准测试系统采用模块化设计：

1. **测试框架**：提供通用的测试执行环境
2. **查询执行器**：负责执行各类查询测试用例
3. **指标收集器**：收集测试过程中的性能指标
4. **结果处理器**：分析和输出测试结果

测试系统支持分布式执行，可以在集群环境中进行大规模性能测试。
