# 开发工具目录 (Development Tools)

## 概述

此目录包含 YTsaurus 开发过程中使用的各种调试和开发工具。这些工具帮助开发者进行代码调试、性能分析和问题诊断。

## 工具集合

### GDB 调试器配置 (gdb/)
- **功能** - GNU Debugger (GDB) 的配置文件和脚本
- **用途** - 增强 C++ 代码调试体验
- **包含内容**：
  - 自定义调试命令
  - 美化输出配置
  - YTsaurus 特定类型显示
  - 自动加载脚本

## 主要功能

### 调试支持
- **智能类型识别** - 自动识别 YTsaurus 核心数据结构
- **内存查看器** - 优化内存布局显示
- **调用栈美化** - 提供更清晰的调用栈信息
- **条件断点** - 支持复杂的断点条件

### 开发辅助
- **代码导航** - 快速跳转到定义
- **变量监视** - 实时监控变量变化
- **表达式求值** - 支持复杂表达式计算
- **多线程调试** - 并发程序调试支持

## 使用方法

### 启动调试会话
```bash
# 使用项目 GDB 配置
gdb -x devtools/gdb/ytsaurus.gdb ./ytserver-all

# 或通过环境变量自动加载
export GDBINIT=$PWD/devtools/gdb/ytsaurus.gdb
gdb ./ytserver-all
```

### 常用调试命令
- `yt-print-<type>` - 打印特定 YTsaurus 类型
- `yt-where` - 显示当前位置上下文
- `yt-backtrace` - 格式化调用栈
- `yt-info` - 显示调试信息

## 开发工具扩展

### 性能分析
虽然此目录主要是调试工具，YTsaurus 项目还使用其他性能分析工具：
- **Perf** - Linux 性能分析器
- **Valgrind** - 内存检查和性能分析
- **AddressSanitizer** - 运行时错误检测
- **ThreadSanitizer** - 并发 bug 检测

### 代码质量
- **Clang-Tidy** - 静态代码分析
- **Clang-Format** - 代码格式化
- **Cppcheck** - C++ 静态分析
