# YTsaurus 库目录 (YTsaurus Libraries)

## 概述

此目录包含 YTsaurus 项目中各种语言的核心库实现。这些库提供了 YTsaurus 的基础功能，包括客户端接口、工具函数、协议实现等。

## 目录结构

### C++ 库 (cpp/)
YTsaurus 的核心 C++ 库集合，包含：

#### 核心组件
- **客户端库** - YTsaurus C++ 客户端实现
- **协议处理** - RPC 协议和序列化
- **工具函数** - 通用工具和辅助函数
- **数据结构** - 核心数据类型和容器

#### 主要模块
- `yt/` - YTsaurus 核心功能
- `core/` - 基础设施和工具
- `table_client/` - 表操作客户端
- `driver/` - 连接驱动实现
- `orm/` - 对象关系映射

### Python 库 (python/)
Python 语言绑定和客户端库：

#### 客户端实现
- **Full Client** - 功能完整的 Python 客户端
- **Lite Client** - 轻量级客户端
- **Async Client** - 异步客户端

#### 工具模块
- `ytsaurus/` - 主要 Python 包
- `yt/` - 兼容性接口
- `wrapper/` - C++ 绑定封装
- `yson/` - YSON 格式处理

### Go 库 (go/)
Go 语言实现的库：

#### 核心功能
- **客户端** - Go 客户端 SDK
- **MapReduce** - MapReduce 框架支持
- **工具函数** - 通用工具库

#### 模块结构
- `client/` - 客户端实现
- `mapreduce/` - 分布式计算框架
- `table/` - 表操作工具
- `ypath/` - 路径处理

### C 库 (c/)
C 语言接口和绑定：

#### 接口层
- **C API** - 标准 C 语言接口
- **绑定层** - C++ 到 C 的桥接
- **错误处理** - C 风格错误处理

## 主要功能

### 数据访问
- **表操作** - 读取、写入、修改表数据
- **文件系统** - 文件和目录操作
- **事务处理** - ACID 事务支持
- **批量操作** - 高效批量数据处理

### 分布式计算
- **MapReduce** - 分布式计算框架
- **Pipeline** - 数据管道处理
- **调度器** - 任务调度和执行
- **资源管理** - 计算资源分配

### 通信协议
- **RPC** - 远程过程调用
- **YSON** - YTsaurus 序列化格式
- **HTTP** - REST API 支持
- **压缩** - 数据压缩传输

## 构建系统

- C++17 或更高版本

## 使用方法

### C++ 客户端
```cpp
#include <yt/client/api/client.h>

int main() {
    auto client = NYT::CreateClient("localhost");
    // 使用客户端...
}
```

### Python 客户端
```python
import yt

client = yt.YtClient("localhost")
# 使用客户端...
```

### Go 客户端
```go
import "github.com/ytsaurus/ytsaurus/go/ytpb"

client := ytpb.NewClient()
// 使用客户端...
```
