# accurate_accumulate

高精度浮点数累加库，实现了 Kahan 求和算法以减少浮点数累加时的精度损失。

## 功能描述

该模块提供了高精度的浮点数累加器，通过 Kahan 求和算法（也称为补偿求和）来显著减少在大量浮点数累加过程中由于精度限制导致的误差累积。

## 核心特性

- **Kahan 求和算法**：实现了经典的 Kahan 求和算法，能够将浮点累加误差从 O(n) 降低到 O(1)
- **模板化设计**：支持不同类型的浮点数（float、double、long double）
- **运算符重载**：提供自然的使用接口，支持常见的比较和赋值操作
- **类型安全**：通过模板和类型约束确保类型安全

## 主要组件

### TKahanAccumulator
核心累加器类，包含以下功能：
- 构造函数支持初始化值
- `Get()` 方法获取精确的累加结果
- 支持赋值、比较等运算符
- 隐式类型转换

## 使用示例

```cpp
#include <library/cpp/accurate_accumulate/accurate_accumulate.h>

// 创建累加器
TKahanAccumulator<double> accumulator;

// 累加大量浮点数
for (int i = 0; i < 1000000; ++i) {
    accumulator += small_value;
}

// 获取精确结果
double result = accumulator.Get();
```

## 实现原理

Kahan 算法通过维护一个补偿变量来记录每次运算中丢失的小数部分，并在下次运算中补偿回来：

1. **主累加器**：存储主要累加结果
2. **补偿器**：存储上次运算丢失的精度
3. **补偿机制**：每次运算前先补偿上次误差，运算后记录新误差
