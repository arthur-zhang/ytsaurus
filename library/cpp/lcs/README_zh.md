# LCS (最长公共子序列) 算法库

## 项目概述

本库提供了一套用于近似字符串匹配的高效算法，主要实现了通过 LIS (最长递增子序列) 来计算 LCS (最长公共子序列) 的组合算法。该算法特别适用于处理大型字母表的情况，如文本中单词哈希值。

## 文件说明

### 核心文件

- **`lcs_via_lis.h`** - 主要算法实现头文件
  - 定义了 `TLCSCtx` 上下文类，包含算法所需的数据结构
  - 实现了基于 LIS 的 LCS 算法
  - 使用内存池优化性能
  - 支持泛型类型，适用于各种数据类型

- **`lcs_via_lis.cpp`** - 算法实现文件
  - 包含具体的算法实现逻辑
  - 处理序列匹配和子序列构建

- **`lcs_via_lis_ut.cpp`** - 单元测试文件
  - 完整的测试套件
  - 包含标准动态规划算法作为参考实现
  - 验证算法正确性

### 测试文件

- **`ut/`** - 测试目录

## 实现原理

### 核心思想

算法将 LCS 问题转换为 LIS 问题：

1. **问题转换**：对于字符串 S1 中的每个字符，在 S2 中找到其所有出现位置
2. **序列构建**：将这些位置按逆序连接，形成一个数字序列
3. **LIS 求解**：在该序列中寻找最长递增子序列
4. **结果映射**：LIS 对应的即为原字符串的最长公共子序列

### 复杂度分析

- **时间复杂度**：O(r log n)
  - 其中 n 是较短序列的长度
  - r 是 S1[i] = S2[j] 的配对数量
  - 对于均匀分布的字母表，期望复杂度为 O(nm/s * log n)

- **空间复杂度**：O(r)
  - 使用内存池优化内存分配
  - 分页向量存储优化大序列处理

### 数据结构

- **TEncounterIndex**：哈希表，记录每个字符在 S2 中的出现位置
- **TCover**：分页向量，存储递增子序列覆盖
- **TLastIndex**：用于构建最后结果的索引结构

### 算法特点

- **高效性**：对于大字母表 (s = O(n)) 特别有效
- **内存优化**：使用内存池和分页向量减少内存碎片
- **灵活性**：支持任意可比较的数据类型
- **可选构建**：可以只计算 LCS 长度而不构建实际序列

## 使用示例

### 基本用法

```cpp
#include "lcs_via_lis.h"

// 使用字符串
std::string s1 = "ABCBDAB";
std::string s2 = "BDCABC";

NLCS::TLCSCtx<char> ctx;
auto result = NLCS::LCSViaLIS(ctx, s1.begin(), s1.end(), s2.begin(), s2.end());

// result 包含 LCS 的长度和实际序列
```

### 处理自定义类型

```cpp
#include "lcs_via_lis.h"

// 处理整数序列
std::vector<int> seq1 = {1, 2, 3, 4, 1};
std::vector<int> seq2 = {3, 4, 1, 2, 1, 3};

NLCS::TLCSCtx<int> ctx;
auto lcs_length = NLCS::LCSLengthViaLIS(ctx, seq1.begin(), seq1.end(), seq2.begin(), seq2.end());
```
