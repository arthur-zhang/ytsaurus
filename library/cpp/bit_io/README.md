# bit_io

高效的位级 I/O 库，提供了紧凑的位读写操作，用于压缩算法、编码器和其他需要位级操作的场景。

## 功能描述

bit_io (Bit I/O) 是一个高性能的位级输入输出库，允许以位为单位进行数据的读取和写入。它特别适用于实现压缩算法、编码器、加密算法等需要精确控制位操作的场景。

## 核心特性

- **位级精度**：支持任意位长度的读写操作
- **高性能**：优化的位操作算法，避免分支预测失败
- **灵活接口**：支持多种数据类型和位长度
- **错误处理**：完善的边界检查和错误处理
- **缓冲优化**：智能缓冲策略，提高 I/O 效率

## 主要组件

### TBitInput
位级输入流，提供：
- 任意位长度读取
- 高效的位偏移管理
- EOF 检测和边界检查

```cpp
template <ui64 bits, typename T>
Y_FORCE_INLINE bool ReadK(T& result, ui64 skipbits);
```

### TBitOutput
位级输出流，提供：
- 任意位长度写入
- 自动缓冲管理
- 刷新和同步机制

### TBitInputImpl / TBitOutputImpl
底层实现类，处理：
- 位操作的具体实现
- 缓冲区管理
- 字节序处理

## 使用示例

### 位级读取
```cpp
#include <library/cpp/bit_io/bitinput.h>

// 从字节数组创建位输入流
TVector<char> data = {0x12, 0x34, 0x56, 0x78};
TBitInput bitInput(data);

// 读取不同位长的数据
ui8 value8;
bitInput.ReadK<8>(value8, 0);  // 读取8位

ui16 value16;
bitInput.ReadK<16>(value16, 0); // 读取16位

// 读取变长位
ui64 value;
bitInput.ReadSafe(value, 13);   // 读取13位
```

### 位级写入
```cpp
#include <library/cpp/bit_io/bitoutput.h>

TVector<char> buffer;
TBitOutput bitOutput(buffer);

// 写入不同位长的数据
bitOutput.WriteK<8>(value8, 0);
bitOutput.WriteK<16>(value16, 0);
bitOutput.WriteSafe(value64, 13);

// 刷新缓冲区
bitOutput.Flush();
```

### 高级功能
```cpp
// 获取位偏移
ui64 bitOffset = bitInput.GetBitOffset();

// 获取字节偏移
ui64 byteOffset = bitInput.GetOffset();

// 检查结束
if (bitInput.Eof()) {
    // 处理结束情况
}
```

## 实现原理

### 位存储格式
位按照从高位到低位的顺序存储：
```
Byte:  7 6 5 4 3 2 1 0
       ^^^^^^^^^^^^
       Read/Write bits
```

### 缓冲策略
- **读取缓冲**：预读取数据到缓冲区
- **写入缓冲**：累积位到字节边界再写入
- **对齐处理**：自动处理字节边界对齐

### 性能优化
1. **模板特化**：编译时确定位长度，避免运行时开销
2. **分支优化**：减少条件分支，提高 CPU 流水线效率
3. **内联函数**：关键路径函数强制内联
4. **SIMD 优化**：批量处理时使用向量指令

## 错误处理

### 边界检查
- 自动检测越界访问
- 返回错误状态或抛出异常
- 提供安全的读取模式

### 错误恢复
- 部分读取失败时的恢复机制
- 损坏数据的检测和跳过
- 详细的错误日志
