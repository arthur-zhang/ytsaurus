# YPath - YTsaurus 路径

本模块提供 YTsaurus 路径（YPath）的操作功能，类似于文件系统路径，用于在 YTsaurus 中定位和操作对象。

## 核心功能

### 1. 路径解析
- **绝对路径**：以 `/` 开头的完整路径
- **相对路径**：相对于当前对象的路径
- **对象ID路径**：使用 `#` 前缀的路径格式

### 2. 路径操作
- **路径合并**：连接多个路径段
- **路径规范化**：简化路径格式
- **父路径获取**：获取父对象路径
- **路径分解**：解析路径的各个组成部分

### 3. 属性访问
- **属性查询**：使用 `@` 访问对象属性
- **批量属性**：支持批量获取多个属性
- **属性修改**：支持修改对象属性

### 4. 特殊路径
- **Cypress节点**：访问 Cypress 中的节点
- **系统路径**：访问系统对象
- **跨集群路径**：访问其他集群的对象

## 路径格式示例

```
# 绝对路径
//home/user/table

# 对象ID路径
#1-2-3-4-5-6-7-8

# 属性访问
//home/user/table/@row_count

# 相对路径
subdirectory/file
```

YPath 是 YTsaurus 中对象定位和操作的基础，为所有客户端操作提供统一的寻址机制。
