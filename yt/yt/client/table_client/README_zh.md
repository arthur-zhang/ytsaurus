# Table Client - 表客户端

本模块提供 YTsaurus 表操作的核心客户端功能，是处理结构化数据的主要接口。

## 核心功能

### 1. 数据模型
- **Schema管理**：定义和管理表结构
- **行数据**：处理版本化和非版本化行
- **列数据**：支持不同数据类型的列
- **名称表**：列名到索引的映射

### 2. 读写操作
- **批量读取**：高效的批量数据读取
- **批量写入**：事务性的批量数据写入
- **流式处理**：支持大数据集的流式处理
- **随机访问**：支持按索引随机访问数据

### 3. 数据类型支持
- 基础类型：int64、uint64、double、boolean、string
- 复合类型：list、map、struct
- 特殊类型：null、any、uuid

### 4. 性能优化
- **数据压缩**：支持多种压缩算法
- **编码优化**：针对不同数据类型的优化编码
- **批处理**：批量操作减少RPC开销
- **预取**：智能数据预取机制

## 主要组件

- **Schema管理器**：处理表结构定义
- **RowBuffer**：高效的行数据内存管理
- **VersionedWriter/Reader**：版本化数据的读写
- **UnversionedWriter/Reader**：非版本化数据的读写
- **NameTable**：列名管理

表客户端是 YTsaurus 数据访问的基础，为上层应用提供高性能的数据操作接口。
