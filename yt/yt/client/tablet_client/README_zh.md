# Tablet Client - Tablet 客户端

本模块提供 YTsaurus Tablet（数据分片）的客户端操作接口，用于与 Tablet 服务进行交互。

## 核心功能

### 1. Tablet 操作
- **读写请求**：向 Tablet 发送读写请求
- **事务支持**：在 Tablet 上执行事务操作
- **负载均衡**：智能路由请求到合适的 Tablet
- **故障转移**：自动处理 Tablet 故障转移

### 2. 数据访问
- **点查询**：根据主键查询单行数据
- **范围查询**：查询指定范围的数据
- **批量操作**：批量读写优化性能
- **索引使用**：利用二级索引加速查询

### 3. 一致性保证
- **强一致性**：确保读写的一致性
- **读取副本**：支持从副本读取以提高可用性
- **事务隔离**：支持不同级别的事务隔离

### 4. 性能优化
- **连接池**：复用连接减少开销
- **批量提交**：聚合多个请求减少RPC
- **缓存机制**：缓存热点数据
- **压缩传输**：减少网络传输量

## 架构设计

Tablet 客户端采用分层的架构设计：
- **Proxy层**：智能代理和路由
- **负载均衡层**：请求分发和负载均衡
- **连接管理层**：连接复用和管理
- **协议层**：定义与 Tablet 的通信协议

该模块是 YTsaurus 分布式表存储的重要组成部分，为上层应用提供高性能、高可用的数据访问能力。
