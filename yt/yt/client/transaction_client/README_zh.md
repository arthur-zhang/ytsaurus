# Transaction Client - 事务客户端

本模块提供 YTsaurus 分布式事务的客户端接口，支持 ACID 事务的创建、管理和提交。

## 核心功能

### 1. 事务管理
- **事务创建**：创建新的事务
- **事务提交**：提交事务使变更持久化
- **事务回滚**：撤销事务中的所有变更
- **事务嵌套**：支持嵌套事务

### 2. 事务类型
- **Master事务**：在 Master 节点执行的元数据事务
- **Tablet事务**：在 Tablet 上执行的数据事务
- **嵌套事务**：在现有事务内创建的子事务
- **上传事务**：用于大数据上传的特殊事务

### 3. 并发控制
- **锁管理**：获取和管理对象锁
- **死锁检测**：自动检测和解决死锁
- **隔离级别**：支持多种事务隔离级别
- **乐观并发**：支持乐观并发控制

### 4. 一致性保证
- **原子性**：事务要么全部成功，要么全部失败
- **一致性**：维护数据的一致性约束
- **隔离性**：事务间相互隔离
- **持久性**：提交的事务永久保存

## 主要特性

- **分布式事务**：跨多个节点的事务支持
- **长时间运行**：支持长时间运行的事务
- **故障恢复**：事务状态持久化和恢复
- **超时管理**：事务超时自动清理

事务客户端是 YTsaurus 保证数据一致性的核心组件，为应用提供可靠的分布式事务能力。
