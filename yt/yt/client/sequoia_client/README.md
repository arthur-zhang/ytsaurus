# YTsaurus Sequoia Client 模块

## 概述

Sequoia Client 模块是 YTsaurus Sequoia 一致性系统的客户端接口，提供分布式一致性保证和协调功能。

## 核心功能

- **一致性协议**: 分布式一致性协议实现
- **协调服务**: 分布式协调和同步
- **状态管理**: 分布式状态管理

## 依赖项

- `yt/yt/core/misc/public.h`

## 相关模块

- **Hydra Client**: 一致性协议
- **Hive Client**: 分布式协调

## 贡献指南

确保分布式一致性的正确实现。
