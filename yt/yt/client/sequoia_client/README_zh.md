# Sequoia Client - Sequoia 客户端

本模块提供 Sequoia 分布式存储系统的客户端接口。Sequoia 是 YTsaurus 的新一代分布式存储解决方案，提供更好的扩展性和性能。

## 核心特性

1. **分布式架构**：支持跨多个节点的分布式存储
2. **强一致性**：提供强一致性保证
3. **高可用性**：自动故障转移和恢复
4. **水平扩展**：支持动态扩展存储容量

## 主要功能

- 分布式事务支持
- 数据分片和复制
- 一致性协议实现
- 元数据管理

Sequoia 使用专门的对象ID范围，通过最高位标识来区分 Sequoia 对象和常规对象。
