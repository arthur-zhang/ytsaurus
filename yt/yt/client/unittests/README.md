# YTsaurus Client Unit Tests

## 概述

本目录包含 YTsaurus 客户端库的单元测试，确保各个模块的功能正确性和代码质量。

## 测试结构

- **功能测试**: 各模块核心功能测试
- **性能测试**: 性能基准测试
- **集成测试**: 模块间集成测试
- **错误处理测试**: 异常情况处理测试

## 运行测试

```bash
# 运行所有单元测试
./run_tests.sh

# 运行特定模块测试
./run_tests.sh --module table_client

# 运行性能测试
./run_tests.sh --performance
```

## 测试指南

1. 为新功能添加对应的单元测试
2. 确保测试覆盖率达到要求
3. 保持测试代码的可维护性
4. 定期运行性能基准测试

## 依赖项

- Google Test 框架
- 模拟测试框架
- 性能测试工具

## 贡献指南

在提交代码时，确保：
1. 所有现有测试通过
2. 新增代码有对应的测试
3. 测试覆盖率不降低
4. 性能测试结果满足要求
