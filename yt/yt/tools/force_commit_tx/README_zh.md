# force_commit_tx - 强制提交事务工具

## 项目描述

`force_commit_tx` 是 YTsaurus 系统的紧急管理工具，用于强制提交指定的事务。该工具主要用于处理异常情况下的故障恢复，当事务无法正常提交但需要保持其操作结果时，可以通过此工具强制提交事务，确保数据持久性。

## 功能特性

- **强制提交事务**：直接向事务参与者发送提交请求
- **精确目标**：基于 cell ID 和事务 ID 进行精确定位
- **时间戳处理**：自动计算合适的提交时间戳
- **网络通信**：通过 RPC 协议与事务参与者通信
- **错误处理**：完善的异常捕获和错误报告机制

## 文件说明

- `main.cpp` - 主程序实现，包含 RPC 通信和事务提交逻辑
- `CMakeLists.txt` - CMake 构建配置文件（支持多平台）
- `ya.make` - YaTool 构建系统配置文件

## 使用方法

### 编译
```bash
# 使用 CMake 构建
cmake --build . --target force_commit_tx

# 或使用 ya 工具构建
ya make force_commit_tx
```

### 运行
```bash
./force_commit_tx <address> <cell_id> <transaction_id>
```

**参数说明：**
- `address` - 事务参与者服务的网络地址（格式：host:port）
- `cell_id` - Tablet Cell 的 ID（GUID 格式）
- `transaction_id` - 要提交的事务 ID（GUID 格式）

## 实现原理

该工具通过以下步骤实现强制事务提交：

1. **参数解析**：从命令行参数获取地址、Cell ID 和事务 ID
2. **RPC 连接**：创建到指定地址的 RPC 通道
3. **Realm 绑定**：将通道绑定到指定的 Tablet Cell
4. **代理创建**：创建事务参与者服务代理
5. **时间戳计算**：基于事务 ID 计算合适的提交时间戳（+100）
6. **提交请求**：构造并发送提交事务请求
7. **等待响应**：同步等待操作完成或失败

## 相关概念

### 事务（Transaction）
YTsaurus 中的原子操作单元，确保多个操作的原子性。事务可以跨越多个 Tablet Cell 执行。

### 事务提交（Transaction Commit）
将事务的所有操作结果永久保存到系统中，使其他事务可以看到这些更改。

### 提交时间戳（Commit Timestamp）
事务提交时的逻辑时间戳，用于确定事务的顺序和可见性。

### 强制提交（Force Commit）
绕过正常的事务协议，直接强制提交事务，通常用于异常恢复场景。

## 最佳实践

### 使用场景
1. **异常恢复**：当事务协调器故障但事务已成功完成时
2. **网络分区**：网络分区导致事务无法正常提交时
3. **协调器故障**：事务协调器进程崩溃但操作已完成时
4. **超时处理**：事务提交超时但确认操作已完成时

### 注意事项
1. **数据一致性**：确保事务的所有操作都已成功完成
2. **依赖检查**：确认强制提交不会与其他事务产生冲突
3. **权限要求**：执行强制提交需要适当的系统权限
4. **备份策略**：在生产环境使用前确保有完整的备份策略

### 安全建议
1. **谨慎使用**：仅在确认事务操作已完成时使用
2. **状态验证**：在强制提交前验证事务的实际状态
3. **日志记录**：记录所有强制提交操作，便于后续审计
4. **测试验证**：在测试环境充分验证后再在生产环境使用

## 与 force_abort_tx 的区别

| 特性 | force_commit_tx | force_abort_tx |
|------|----------------|----------------|
| 目的 | 保存事务结果 | 撤销事务操作 |
| 数据影响 | 持久化更改 | 回滚更改 |
| 使用时机 | 确认操作完成时 | 异常情况需要清理时 |
| 风险级别 | 中等 | 高 |

## 错误处理

### 常见错误类型
1. **连接错误**：无法连接到指定的事务参与者服务
2. **权限错误**：没有执行强制提交的权限
3. **参数错误**：提供的 Cell ID 或事务 ID 格式不正确
4. **事务不存在**：指定的事务 ID 不存在或已完成
5. **时间戳冲突**：计算的时间戳与其他事务冲突

### 错误恢复
- 检查网络连接和服务状态
- 验证参数格式的正确性
- 确认权限和访问控制设置
- 查看系统日志获取详细信息
- 验证事务的实际状态
